# DhruvGPT - AI Chatbot with OpenAI, n8n & Lovable

## Overview

DhruvGPT is an AI-powered chatbot built using OpenAI, n8n, and Lovable. It combines a modern chat interface with workflow automation to deliver real-time, context-aware conversations.

The chatbot uses OpenAI's language models to generate intelligent responses, while n8n manages backend orchestration, webhook communication, conversation memory, and request processing.

* Webhook-based communication

## Workflow Architecture

1. User sends a message through the chatbot interface.
2. The message is sent to an n8n Webhook.
3. n8n processes the request and forwards it to the AI Agent.
4. The AI Agent interacts with OpenAI to generate a response.
5. Conversation memory maintains context across interactions.
6. The response is returned to the chatbot interface in real time.
